# Marginália

Instaladores e atualizações do app desktop Marginália, uma plataforma pessoal de estudos: biblioteca e leitor de PDFs, notas em Markdown com LaTeX, cronograma, trilhas, flashcards com repetição espaçada, simulados, foco (pomodoro) e estatísticas. O código-fonte fica em um repositório privado.

## Baixar

Versão **1.0.12**

- **Windows x64**: [Baixar `.exe`](https://github.com/IcaroGundim/marginalia-releases/releases/download/v1.0.12/Marginalia_1.0.12_x64-setup.exe) (não precisa de administrador) ou [`.msi`](https://github.com/IcaroGundim/marginalia-releases/releases/download/v1.0.12/Marginalia_1.0.12_x64_pt-BR.msi)
- **macOS Apple Silicon**: [Baixar `.dmg`](https://github.com/IcaroGundim/marginalia-releases/releases/download/v1.0.12/Marginalia_1.0.12_aarch64.dmg)
- **Linux x86-64**: [Baixar `.deb`](https://github.com/IcaroGundim/marginalia-releases/releases/download/v1.0.12/Marginalia_1.0.12_amd64.deb)
- **Android**: [Baixar o APK](https://github.com/IcaroGundim/marginalia-releases/releases/tag/android) (abre um servidor Marginália; não tem modo offline)

[Todas as versões](https://github.com/IcaroGundim/marginalia-releases/releases)

## Novidades da 1.0.12

- Quando o servidor não conecta, **Usar este computador** volta a abrir os dados locais.
- Nova opção **Usar sempre este computador**: desliga o app do servidor sem perder o registro na rede. Para voltar, basta **Entrar com Tailscale** com o mesmo endereço.
- Em redes que bloqueiam o Tailscale, o app avisa em segundos o que está acontecendo e como resolver, em vez de ficar esperando.

## Atualizações

O app instalado confere sozinho se há versão nova e oferece a atualização ao abrir. Não é preciso baixar de novo por aqui.
